Protección del sticker

Proteger con una clave (se puede desbloquear) recomendado

Después de grabarlo acá, con la app gratuita NFC Tools (Android · iPhone):

  1. Otros → Establecer contraseña, escribí una clave y acercá el sticker.
  2. Guardá la clave: solo el personal la conoce.
  3. Para volver a grabarlo: Otros → Quitar contraseña con esa clave, y después grabalo desde acá.

La clave la maneja la app porque Chrome no permite usar esa función de los stickers desde una página web.

Cómo grabarlos desde este celular

  1. Instalá la app gratuita NFC Tools: descargar.
  2. Acá abajo tocá Copiar link en la mesa.
  3. En NFC Tools: Escribir → Agregar un registro → URL / URI, pegá el link y tocá Escribir.
  4. Acercá el sticker a la parte de arriba del celular hasta que confirme.
  5. Para protegerlo con una clave (recomendado): Otros → Establecer contraseña. Para volver a grabarlo: Otros → Quitar contraseña. (También existe Otros → Bloquear etiqueta, pero es permanente.)

Escaneá este código con tu celular

Se abre esta misma página en el teléfono (Android o iPhone) para grabar y bloquear los stickers. No hace falta iniciar sesión.
